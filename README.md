# Поиск похожих людей по фотографии

## Тема НИРС

Поиск похожих людей по фотографии.

## Группа

ИУ5-53б.

## Состав команды

1. **Андреев Герман** — поиск: BM25 и корпус данных. Собирает документы, выполняет токенизацию и предобработку, самостоятельно реализует индекс и BM25. Готовит тестовые запросы — минимум три релевантных документа на каждый. Рассчитывает Recall@k и MRR, анализирует ошибки поиска.
2. **Стариков Михаил** — бэкенд и интеграция с LLM. Разрабатывает API, принимает запрос пользователя, вызывает поиск, передаёт найденные документы в LLM и возвращает ответ с источниками. Настраивает ключи, обработку ошибок и запуск приложения. Подключает получение текстового описания изображения.
3. **Гуськов Дмитрий** — продукт и интерфейс. Определяет пользователя и основной сценарий. Разрабатывает экран загрузки фотографии, карточки результатов, ответ и просмотр источников. Готовит демонстрационный сценарий и собирает презентацию из материалов команды.
