# LookAlike — поиск похожих публичных людей по фотографии

Учебный НИРС-проект группы **ИУ5-53б**. Пользователь загружает портрет, система получает его текстовое описание, ищет по проверенному корпусу публичных персон и показывает визуально похожие типажи с объяснением и источниками.

> Сейчас реализованы продуктовая документация и интерактивный frontend-прототип. Компьютерное зрение, BM25, backend и LLM пока представлены контрактами и демонстрационными данными — это честно отражено в [STATUS.md](STATUS.md).

## Пользователь и ценность

**Основной пользователь:** ассистент по кастингу, режиссёр или автор визуального проекта, которому нужны узнаваемые референсы типажа, а не идентификация человека на снимке.

**Что он получает:** до пяти ранжированных карточек публичных персон: фотографию, имя, профессию, процент релевантности, краткое объяснение совпавших признаков и ссылки на источники. Результат можно сохранить как подборку для обсуждения с командой.

Сервис не распознаёт личность, не подтверждает родство и не предназначен для поиска частных лиц.

## Основной сценарий

1. Пользователь загружает портрет в JPG, PNG или WebP до 10 МБ.
2. Интерфейс показывает превью и позволяет подтвердить запуск анализа.
3. Модель компьютерного зрения формирует нейтральное текстовое описание внешних признаков.
4. BM25 ранжирует документы корпуса публичных персон, backend передаёт лучшие результаты в LLM.
5. Пользователь получает карточки похожих типажей и объяснение сходства, открывает источники или меняет фото.

Подробности: [пользовательские сценарии](docs/product/scenarios.md), [требования](docs/product/requirements.md) и [поведение интерфейса](docs/product/interface.md).

## Быстрый запуск прототипа

Нужны Node.js 20+ и npm.

```bash
cd frontend
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:5173`). Проверка production-сборки: `npm run build`.

## Демонстрация контрольной точки

Загрузить изображение → подтвердить анализ → показать ранжированные карточки → открыть панель источников → пояснить, что выдача демонстрационная, а BM25, LLM и API ещё не подключены.
