# Статус проекта

Актуально на 16 октября 2026 года.

| Компонент | Статус | Что есть сейчас |
| --- | --- | --- |
| Product/SDD-документация | Готово для контрольной точки | Пользователь, основной и альтернативные сценарии, требования, состояния UI |
| Frontend | Интерактивный прототип | Загрузка и превью фото, валидация, демо-анализ, карточки, источники, адаптивность |
| Корпус персон | Проектируется | Описана схема документа и требования к источникам |
| BM25 | Не реализован | Зафиксирован контракт поиска и метрики Recall@k/MRR |
| Backend API | Не реализован | Описаны endpoint, ответы и ошибки |
| Описание фото | Не реализовано | В прототипе используется заранее подготовленное описание |
| LLM/RAG | Не реализован | В прототипе используются демонстрационные объяснения |

Frontend не отправляет загруженную фотографию на сервер: файл читается только браузером для локального превью.
