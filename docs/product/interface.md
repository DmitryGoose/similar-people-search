# Интерфейс и поведение

## Экран поиска

В шапке размещены название, отметка «Прототип» и ссылка на раздел о методе. Hero-блок отвечает на три вопроса: что сделать, что получится и какие есть ограничения. Центральный блок загрузки поддерживает выбор и drag-and-drop.

## Состояния

| Состояние | Что видит пользователь | Доступное действие |
| --- | --- | --- |
| Пустое | Требования к фото и область загрузки | Выбрать файл |
| Фото выбрано | Превью, имя, размер, сообщение о локальной обработке | Найти похожих / удалить |
| Обработка | Этапы «Описание → Поиск → Объяснение» | Дождаться или отменить сменой страницы |
| Результат | Резюме, карточки и источник выбранной карточки | Открыть источник, сохранить, новое фото |
| Ошибка файла | Пояснение под загрузчиком | Выбрать другой файл |
| Нет результатов | Причина и совет по качеству снимка | Загрузить другой портрет |

## Карточка результата

Карточка содержит портрет-заглушку, имя, профессию, бейдж релевантности, список совпавших признаков, кнопку источников. Оценка подписана «релевантность», а не «сходство личности».

## Адаптивность

На широком экране карточки выводятся сеткой. До 760 px hero, загрузчик и результаты становятся одноколоночными; кнопки растягиваются на ширину. Минимальная целевая ширина — 360 px.

## Доступность и язык

- Загрузчик связан с нативным `input type=file`.
- Статус поиска объявляется через `aria-live`.
- Интерактивные элементы имеют текстовые названия и `:focus-visible`.
- Ошибка описывает исправление, не использует внутренние коды.
- Цвет не является единственным носителем состояния.
