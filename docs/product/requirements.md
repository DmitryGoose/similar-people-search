# Требования

Статусы: **Есть** — реализовано в прототипе; **Частично** — показано на демо-данных; **Нет** — целевое поведение ещё не реализовано.

| ID | Требование | Проверка | Статус |
| --- | --- | --- | --- |
| REQ-01 | Пользователь видит назначение сервиса и ожидаемый результат до загрузки файла. | Первый экран | Есть |
| REQ-02 | Принимаются JPG, PNG, WebP размером не более 10 МБ. | Валидный файл, PDF, файл 11 МБ | Есть |
| REQ-03 | После выбора файла показываются превью, имя и размер. | UC-01 | Есть |
| REQ-04 | Фото не отправляется до явного запуска поиска. | Network/devtools | Есть |
| REQ-05 | Во время обработки видны текущий этап и запрет повторного запуска. | UC-01 | Есть, имитация |
| REQ-06 | Результаты отсортированы по убыванию релевантности. | Значения карточек | Есть, демо-данные |
| REQ-07 | Карточка содержит имя, деятельность, релевантность и объяснение. | UC-01 | Есть |
| REQ-08 | Для результата доступен источник с URL и датой проверки. | UC-07 | Есть, демо-данные |
| REQ-09 | Пользователь может сохранить подборку локально. | Нажатие «Сохранить подборку» | Есть |
| REQ-10 | При ошибке сохраняется возможность повторить запрос или сменить фото. | UC-02, UC-06 | Частично |
| REQ-11 | Интерфейс работает от 360 px без горизонтальной прокрутки. | 360/768/1440 px | Есть |
| REQ-12 | Основные действия доступны с клавиатуры и имеют видимый фокус. | Tab/Enter/Space | Есть |
| REQ-13 | Backend принимает фото и возвращает результаты по контракту API. | Интеграционный тест | Нет |
| REQ-14 | Описание изображения не содержит чувствительных выводов. | Набор контрольных фото | Нет |
| REQ-15 | BM25 выдаёт не более пяти документов выше порога. | Benchmark | Нет |
| REQ-16 | Поиск измеряется Recall@5 и MRR на размеченном наборе. | Повторяемый benchmark | Нет |
| REQ-17 | LLM объясняет только признаки и факты из найденных документов. | Проверка цитат | Нет |
| REQ-18 | Загруженный файл удаляется после обработки и не попадает в логи. | Backend-аудит | Нет |

## Нефункциональные требования

- Целевое время ответа p95 — не более 8 секунд.
- API возвращает машинно-читаемый код и безопасное пользовательское сообщение.
- Интерфейс соответствует WCAG: контраст, подписи полей, фокус, `aria-live` для статуса.
- Источник каждого документа корпуса проверяется и имеет дату актуализации.
