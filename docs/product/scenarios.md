# Пользователи и сценарии

## Роли

| Роль | Задача | Доступ |
| --- | --- | --- |
| Гость | Понять идею и попробовать демонстрацию | Загрузка фото, демо-результаты, источники |
| Ассистент по кастингу | Получить и сохранить референсы типажа | Целевой полный сценарий |
| Редактор корпуса | Проверять документы и источники | Будущий служебный интерфейс, не входит в прототип |

## UC-01 — основной сценарий

**Предусловие:** пользователь открыл приложение, фотография содержит одно хорошо различимое лицо.

1. Пользователь выбирает или перетаскивает JPG/PNG/WebP.
2. Система проверяет формат и размер, показывает превью и уведомление о приватности.
3. Пользователь нажимает «Найти похожих».
4. Система показывает этапы обработки.
5. Система выводит карточки по убыванию релевантности и краткое резюме признаков.
6. Пользователь открывает карточку и проверяет источники.
7. Пользователь сохраняет подборку либо выбирает другое фото.

**Результат:** получена объяснимая подборка публичных людей, пригодная как визуальный референс.

## Альтернативные сценарии

| ID | Ситуация | Ожидаемое поведение |
| --- | --- | --- |
| UC-02 | Неверный формат или файл больше 10 МБ | Файл не принимается, причина и допустимые форматы показаны рядом с полем |
| UC-03 | Лицо не обнаружено | Система просит выбрать портрет анфас с хорошим освещением |
| UC-04 | На фото несколько лиц | Система просит кадрировать изображение или выбрать одно лицо |
| UC-05 | Совпадений недостаточно | Показывается пустое состояние без нерелевантных карточек |
| UC-06 | Backend/LLM недоступен | Фото остаётся в интерфейсе, появляется действие «Повторить»; выдуманный ответ не показывается |
| UC-07 | Пользователь открывает источник | Открывается панель с названием документа, URL и датой проверки |
| UC-08 | Пользователь меняет фото | Предыдущая выдача очищается только после подтверждения нового поиска |

## Демонстрационный сценарий

Для контрольной точки UC-01 воспроизводится на локальных демонстрационных данных. Загрузка и состояния интерфейса работают, но фотография не анализируется и на сервер не отправляется.
