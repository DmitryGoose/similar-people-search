# Контракт API

## `POST /api/v1/search`

Запрос: `multipart/form-data`, поле `image`. Допустимые типы: `image/jpeg`, `image/png`, `image/webp`; максимум 10 МБ.

Успешный ответ `200`:

```json
{
  "requestId": "req_01J...",
  "description": "овальное лицо, короткие тёмные волосы, выраженные скулы",
  "results": [
    {
      "personId": "person_0042",
      "name": "Имя персоны",
      "occupation": "актёр",
      "score": 0.87,
      "matchedTraits": ["форма лица", "причёска", "линия бровей"],
      "explanation": "Совпали описанные визуальные признаки…",
      "sources": [
        {"title": "Официальная биография", "url": "https://example.org", "checkedAt": "2026-10-16"}
      ]
    }
  ]
}
```

## Ошибки

| HTTP | Код | Значение |
| --- | --- | --- |
| 400 | `INVALID_IMAGE` | Формат или содержимое файла не поддерживается |
| 413 | `IMAGE_TOO_LARGE` | Файл больше 10 МБ |
| 422 | `FACE_NOT_FOUND` | Лицо не обнаружено |
| 422 | `MULTIPLE_FACES` | Обнаружено несколько лиц |
| 429 | `RATE_LIMITED` | Слишком много запросов |
| 503 | `SEARCH_UNAVAILABLE` | Поиск временно недоступен |

Ответ ошибки содержит `requestId`, `code` и безопасное поле `message`. В логах не сохраняются фото и полное текстовое описание внешности.
