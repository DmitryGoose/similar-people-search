# План проверки

## Автоматическая проверка

```bash
cd frontend
npm install
npm run build
```

Сборка включает проверку TypeScript.

## Ручной чек-лист

1. Открыть приложение при ширине 1440 px и 360 px.
2. Попробовать PDF — увидеть понятную ошибку.
3. Загрузить JPG/PNG — увидеть локальное превью и сведения о файле.
4. Запустить анализ — увидеть последовательность этапов и заблокированную кнопку.
5. Проверить сортировку карточек, объяснения и источник.
6. Сохранить подборку — увидеть подтверждение и проверить `localStorage`.
7. Выбрать другое фото — убедиться, что интерфейс вернулся к состоянию превью.
8. Пройти основные действия клавишей Tab и проверить видимый фокус.

## Что проговорить на показе

- пользователь — ассистент по кастингу, результат — объяснимая подборка референсов;
- интерфейс работает на демонстрационных данных;
- Vision, BM25, API и LLM ещё не подключены;
- качество будущего поиска будет проверяться Recall@5 и MRR;
- сервис ограничен публичными персонами и не идентифицирует человека.
